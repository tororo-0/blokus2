# 仕様書
## レイアウト
### ターン
- 画面上部
- 現在のプレイヤーの色を表示
### ボード
- グレー
- 20*20マス
- 画面中央
- 内部からの返り値(配列)を基に表示
- R=赤
- B=青
- Y=黄色
- G=緑
- W=白(未配置)
- O=黒(選択中)
### ピース
- 画面下部
- 現在のターンのプレイヤーの持っているピースを表示
- 色に合わせてピースの色を変更
### 背景
- 白
